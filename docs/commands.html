📘 CODE KAISE LIKHEIN / HOW TO WRITE CODE

Code seedha paste karo — function / module.exports ki zaroorat nahi (woh bhi chalta hai). Do style chalte hain:
Bot style (doosre bots jaisa):
• text — poora message (misal .sendchannel 1203… Salam; prefix kuch bhi ho, text hamesha . se shuru), args (command ke baad words), command, sender, isOwner, isGroup
• m.reply('text'), m.react('🔥'), m.chat (yehi chat), m.sender, m.quoted.text
• sock.sendMessage(jid, { text }) — sirf: yehi chat, bot ka apna number, ya channel (jid …@newsletter). Content: text / image / video / audio (https link) + caption, react. Ek command max 5 sendMessage, har number max 20 / minute. Koi aur jid → ❌ Ye jid allowed nahi
Purana style: ctx.reply, ctx.sendImage(link, caption), ctx.react, ctx.args, ctx.text, ctx.get(url), ctx.getJson(url)
Aur ye bhi chalta hai / Also allowed:
• Delay: await sleep(2000), await delay(2000), setTimeout(fn, ms) — poori command max 15 sec
• Web: axios.get / axios.post, fetch — sirf https, 5 sec, jawab max 1 MB, local / private IP band, ek command max 5 requests
• require('axios'), require('path'), require('fs') (fs sirf is command ka apna temp folder, max 5 MB)
Example 1 — channel pe message (naam: sendchannel, use: .sendchannel 120363xxx@newsletter Salam doston!) 
if (text.startsWith('.sendchannel ')) {
  const args = text.split(' ')
  const channelJid = args[1]
  const messageText = args.slice(2).join(' ')
  if (!channelJid || !messageText) {
    return m.reply('❌ Tareeqa: .sendchannel 120363xxx@newsletter Salam doston!')
  }
  try {
    await sock.sendMessage(channelJid, { text: messageText })
    m.reply('✅ Message channel mein bhej diya gaya!')
  } catch (e) {
    m.reply('❌ Error: Bot channel ka admin hai? JID sahi hai?')
  }
}

Yaad rakho / Not allowed:
• process, child_process, bot ki files / settings / session, asli fs (temp folder ke bahar), eval, baaki modules — safety ke liye band.
• Command 3 sec CPU / 15 sec total mein khatam honi chahiye, ek command max 5 messages.
• Built-in command (menu, ping, song...) ke naam pe nayi command nahi banti.
• Error aaye to owner ko ❌ Command error aata hai, bot kabhi band nahi hota.
• Save ke ~5-10 sec baad WhatsApp pe .naam likh ke try karo. .menu mein CUSTOM section mein dikhegi (👑 = sirf owner).
